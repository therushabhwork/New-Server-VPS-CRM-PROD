# Implementation Plan: Re-Assignment & Multi-Owner Revision Lifecycle ($R0 \to R1$)

> [!IMPORTANT]
> **PLAN ONLY — DO NOT IMPLEMENT**. As explicitly requested, this updated plan details the architectural analysis and step-by-step implementation for maintaining owner separation across **My Accounts** (`/accounts/my-accounts?stage=new&page=1`), **Deals View** (`/deals/view`), and **Quotations Manager**, while leaving the normal quotation generation cycle 100% untouched. No code changes will be made until your approval.

---

## 1. Executive Summary & Workflow Scenarios

### Scenario A: Normal Quotation Cycle (Zero-Touch / Preserved)
*When accounts/deals are NOT re-assigned*:
1. **No Quotation Generated**:
   - Accounts table (`/accounts/my-accounts?stage=new&page=1`): Quotation No = `-`, Quotation Owner = `-`.
   - Deals table (`/deals/view`): Quotation No = `-`, Quotation Owner Name = `-`.
2. **Quotation Generated ($R0 \to R1 \to R2$)**:
   - Normal cycle is completely preserved. The creator owns all revisions, tables show the active revision number and owner, and Revision History lists each revision under that creator.

---

### Scenario B: Re-Assignment Without Quotation Generated
*When an account or deal is re-assigned to Naim Vhora BEFORE any quotation is created*:
1. **Accounts Table (`/accounts/my-accounts?stage=new&page=1`)**:
   - **Account Owner**: Updates to **`Naim Vhora`**.
   - **Quotation No**: Remains **`-`** (no phantom quotation number).
   - **Quotation Owner**: Remains **`-`** (no phantom quotation owner).
2. **Deals Table (`/deals/view`)**:
   - **Deal Owner**: Updates to **`Naim Vhora`**.
   - **Quotation No**: Remains **`-`**.
   - **Quotation Owner Name**: Remains **`-`**.

---

### Scenario C: Re-Assignment With Quotation Generated ($R0$ Keval V Shah $\to R1$ Naim Vhora)
*When a quotation exists prior to re-assignment*:
1. **$R0$ Generated by Keval V Shah**:
   - Quotation Number: **`...-R0`**
   - Tables Display (`/quotations`, `/accounts/my-accounts`, `/deals/view`): Owner = **`Keval V Shah`**.
   - Revision History Modal: Row $R0$ Owner = **`Keval V Shah`**.
2. **Re-assignment to Naim Vhora**:
   - Deal / Account Owner updates to **`Naim Vhora`**.
   - Quotation preserves `originalOwner = 'Keval V Shah'` permanently in the database.
   - History is never overwritten.
3. **$R1$ Generated by Naim Vhora**:
   - **Main Tables Display** (`/quotations`, `/accounts/my-accounts`, `/deals/view`):
     - Quotation Number updates to **`...-R1`**.
     - Table Quotation Owner updates to **`Naim Vhora`** (reflecting the creator of the active revision $R1$).
   - **Revision History Modal** (accessible from Quotations, Deals, or Accounts):
     - **Row $R0$**: Owner column permanently displays **`Keval V Shah`** (creator of $R0$).
     - **Row $R1$**: Owner column displays **`Naim Vhora`** (creator of $R1$).
   - Subsequent revisions ($R2$, $R3$...) follow this identical isolation: each row in the Revision History modal permanently shows the specific user who generated that revision.

## 2. Root Cause Analysis & Cross-Page Architecture

| Area / Page | Current Behavior | Required Behavior |
| :--- | :--- | :--- |
| **Normal Quotation Generation Cycle** | Works as standard single-user progression. | **Keep 100% untouched**; must not regress or alter single-user flows. |
| **Accounts Table (`/accounts/my-accounts?stage=new&page=1`)** | `getQuotationOwnerName` inspects flat fields (`selectedAccountOwner`, etc.). If unquoted, displays empty/`-`. | If no quotation: displays `-` for Quotation No & Quotation Owner. When quoted with $R1$: resolves latest revision owner (**`Naim Vhora`**). |
| **Deals View Table (`/deals/view`)** | `getQuotationOwnerFromRecord` checks static fields before revisions. | If no quotation: displays `-`. When quoted with $R1$: inspects latest revision first and displays **`Naim Vhora`**. |
| **Top-Level Quotation Record after $R1$** | `selectedAccountOwner` or `quotationOwner` may retain $R0$'s creator if `...payload` spreads without explicit owner override. | Top-level active owner (`selectedAccountOwner`, `quotationOwner`, `quotationOwnerName`, `dealOwner`) explicitly updates to active creator (**`Naim Vhora`**), while `originalOwner` is preserved as **`Keval V Shah`**. |
| **`revisions` Array in MongoDB** | If $R0$ entry didn't explicitly store `owner: 'Keval V Shah'`, it could be populated with current actor on update. | Index 0 ($R0$) permanently stores `owner: 'Keval V Shah', createdByName: 'Keval V Shah'`. Index 1 ($R1$) permanently stores `owner: 'Naim Vhora', createdByName: 'Naim Vhora'`. |
| **Main Quotations Table (`/quotations` & `/admin/quotation-manager/view`)** | `resolveQuotationOwner` checks static fields in arbitrary order, which might show $R0$'s owner even when $R1$ is active. | `resolveQuotationOwner` inspects the latest revision in `revisions` array first; if $R1$ is active, owner displays **`Naim Vhora`**. |
| **Revision History Modal** | Fallback logic might blur $R0$ owner if root owner changed. | Row $R0$ displays `Keval V Shah`; Row $R1$ displays `Naim Vhora`. |

## 3. Step-by-Step Implementation Plan

### Step 1: Backend Quotation Revision Creation (`server/services/quotationService.js`)
1. **Preserve `originalOwner` & Update Current Owner on Revision ($R1$)**:
   - In `quotationService.create` when `existingMatch` is found:
     ```javascript
     const originalOwnerName = existingMatch.originalOwner || existingMatch.createdByName || existingMatch.selectedAccountOwner || 'Keval V Shah'
     const activeCreatorName = actor?.name || existingMatch.dealOwner || 'Naim Vhora'
     ```
   - In `updatedRevisionsList`:
     - Ensure $R0$ retains:
       ```javascript
       owner: originalOwnerName,
       createdByName: originalOwnerName,
       ```
     - Ensure $R1$ receives:
       ```javascript
       owner: activeCreatorName,
       createdBy: actor?.id,
       createdByName: activeCreatorName,
       ```
   - In `updatePayload`:
     - Explicitly set:
       ```javascript
       originalOwner: originalOwnerName,
       selectedAccountOwner: activeCreatorName,
       accountOwner: activeCreatorName,
       quotationOwner: activeCreatorName,
       quotationOwnerName: activeCreatorName,
       dealOwner: activeCreatorName,
       ```
     - Preserves `Keval V Shah` permanently on $R0$, while stamping `Naim Vhora` on $R1$ and document-level active ownership.

---

### Step 2: Deal & Account Re-Assignment Sync (`server/services/dealService.js`)
1. **Non-Destructive Quotation Re-Assignment**:
   - When a deal is re-assigned to `Naim Vhora`:
     - Update `dealOwner` and `assignedTo`.
     - When syncing to quotations:
       - Update `selectedAccountOwner`, `dealOwner`, `quotationOwner`, `quotationOwnerName` to `Naim Vhora` for active workflow.
       - **Do NOT modify** `originalOwner` or `revisions[0].owner` (Keval V Shah).
       - Ensure `originalOwner` is preserved via conditional check if missing:
         ```javascript
         if (!existingQuote.originalOwner) {
           quoteUpdateSet.originalOwner = existingQuote.createdByName || existingQuote.selectedAccountOwner || 'Keval V Shah'
         }
         ```
   - If no quotation is linked to the deal/account, no quotation record is created, and table lookups cleanly return `-`.

---

### Step 3: Quotation Builder Form Submission (`src/pages/quotations/Quotations.jsx`)
1. **Dynamic Creator Assignment for Revision Payloads**:
   - In `handleGenerateQuotation`:
     - When generating $R1$:
       - In `builtRevisions`:
         - $R0$ entry: `owner: quotationForm.originalOwner || 'Keval V Shah'`
         - $R1$ entry: `owner: user?.name || 'Naim Vhora'`
       - In `payload`:
         - `originalOwner: quotationForm.originalOwner || 'Keval V Shah'`
         - `selectedAccountOwner: user?.name || 'Naim Vhora'`
         - `accountOwner: user?.name || 'Naim Vhora'`
         - `dealOwner: user?.name || 'Naim Vhora'`
     - When generating normal (non-reassigned) quotations ($R0$ or higher by same user):
       - Behavior remains untouched; standard current user ownership applies.

---

### Step 4: Table Display & Owner Resolution (`src/pages/admin/quotations/quotationShared.jsx`)
1. **Active Revision Owner Resolution in `resolveQuotationOwner`**:
   - Inspect the latest revision in `revisions` array first:
     ```javascript
     const revisions = quotation.revisions || rawQuotation.revisions || rawData.revisions
     if (Array.isArray(revisions) && revisions.length > 0) {
       const latestRev = revisions[revisions.length - 1]
       const latestOwner = latestRev?.owner || latestRev?.createdByName || latestRev?.ownerName
       if (latestOwner && typeof latestOwner === 'string' && latestOwner.trim()) {
         return latestOwner.trim()
       }
     }
     ```
2. **Per-Row Isolation in `RevisionsListModal`**:
   - In `RevisionsListModal`:
     - For each revision entry in `revisionRowsMap`:
       - If `revCode === 'R0'`: displays `revItem.owner || q.raw?.originalOwner || 'Keval V Shah'`.
       - If `revCode === 'R1'`: displays `revItem.owner || revItem.createdByName || 'Naim Vhora'`.

---

### Step 5: Deals View Table Sync (`src/pages/deals/Deals.jsx`)
1. **Unquoted Deals**:
   - If no quotation exists, `quotationNumber` and `quotationOwnerName` display `-`.
2. **Active Revision Owner in `getQuotationOwnerFromRecord`**:
   - Inspect the latest revision in `record.revisions` first:
     - For $R1$: returns **`Naim Vhora`**.
     - For $R0$: returns **`Keval V Shah`**.
   - Ensures grid column `Quotation Owner Name` in `/deals/view` shows `Naim Vhora` when $R1$ is generated.

---

### Step 6: My Accounts Board & Table Sync (`src/pages/admin/accounts/MyGroupAccountsPage.jsx`)
1. **Unquoted Accounts (`/accounts/my-accounts?stage=new&page=1`)**:
   - When no quotation is matched: `quotationNumber` and `quotationOwnerName` continue to display `-` as designed.
   - When account is re-assigned, `accountOwner` updates to `Naim Vhora`, while `quotationNumber` and `quotationOwnerName` remain `-`.
2. **Quoted Accounts with $R1$**:
   - In `getQuotationOwnerName` (line 222):
     - Check `quotation.revisions` latest entry first.
     - For $R1$: returns **`Naim Vhora`**.
     - For $R0$: returns **`Keval V Shah`**.
   - `enrichBoardDataWithQuotationFields` accurately sets `quotationNumber` to `...-R1` and `quotationOwnerName` to `Naim Vhora`.
